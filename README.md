# How Are You?

Three fast, teacher-led classroom games for practising **“I'm + emotion.”** Children answer aloud; the teacher controls reveals and scoring.

## Run locally

```bash
npm install
npm run dev
```

## Controls

- `Space` — reveal or continue
- `N` — next round
- `R` — reveal
- `1` / `2` — award a team point
- `Esc` — return to the menu

Replace the eight files in `public/assets/emotions/` with your own monkey PNGs at any time. Keep the existing filenames.
